How can a robot turn continuous demonstrations into reusable concepts for planning?

My thesis extends Learning Abstract Models for Planning (LAMP) with clustering-based relational abstractions. The goal: a simpler learning setup that still supports multi-step robot tasks.

THE CONTRIBUTION

From method to working system.

I developed the region-construction pipeline using complete-linkage clustering, recurrence filtering, connected regions, and Gaussian mixture fitting. I also integrated memory-aware parallel processing and migrated learning and execution from Python 2.7 to Python 3.10.

Completed simulated tasks in Packing, Keva, CafeWorld, and DinnerTable demonstrate that the learned models remain usable for planning and motion execution.

01 / EMBEDDED PERCEPTIONSYSTEM SKETCH

EDGE AI · COMPUTER VISION

ReflexDodgeBot

Monocular depth estimation and Kalman tracking turn a camera feed into evasive motion on NVIDIA Jetson Nano.

Jetson NanoTensorRTMonocular vision
Explore project ↗

The challenge

Detect approaching objects and decide how to move using a single RGB camera on constrained embedded hardware.

The approach

Combined monocular depth estimation with Kalman-based motion tracking and an omnidirectional Mecanum drive. Explored YOLOv8n detection and TensorRT/FP16 optimization for on-device inference.

Performance depends on the model and pipeline configuration; no single frame-rate figure is claimed here.

02 / SIMULATION → HARDWARESYSTEM SKETCH

MANIPULATION · DIGITAL TWINS

A robot that solves the maze

A MyCobot Pro 600 digital twin connects image-based maze recognition, path planning, and physical robot control.

MATLAB / SimulinkKinematicsBFS
Explore project ↗

The challenge

Translate a maze image into a path a physical robot arm can trace with its end effector.

The approach

Built forward and inverse kinematics models and a MATLAB–Simulink digital twin. Used image processing to extract the maze, breadth-first search to find a route, and closed-loop control to execute it.

Validation

Tested the strategy in simulation and validated maze tracing on the physical MyCobot Pro 600.
